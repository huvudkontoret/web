// KOMMANDON

Ett kommando
per händelse

Projekt skapas första gången du nämner dem. En ny start stoppar den som går. Framtiden går inte att logga.

$kl
timern som går och dagens summa
$kl start fyr -n "skiss"
startar en timer, stoppar den som går
$kl stop --at 17:00
stoppar vid ett klockslag som redan varit
$kl add fyr 09:00-11:30 --yesterday
lägger till ett pass i efterhand
$kl report week
ISO-veckan per projekt, måndag först
$kl week close
stänger veckan, kl week open öppnar den igen
$kl "jobbade 09-11 på fyr igår"
svenska, tolkat och bekräftat innan det sparas
$kl mcp
samma kommandon som verktyg för agenter
// YTOR

En logg, många ytor

Alla ytor läser samma logg och skriver genom samma vakter.

  • kl

    [ OK ]

    CLI:t och kl tui i helskärm. Skriptbart, --json överallt, stdout är data och stderr är notiser.

  • kl mcp

    [ OK ]

    Nio kl_*-verktyg över stdio. Agenter rapporterar tid genom samma vakter som du.

  • kl-bar

    [ OK ]

    Menyraden på Macen: timern i en blick, start och stopp, synk var femte minut.

  • iPhone

    [ OK ]

    En full kopia av loggen i telefonen. Synkar när appen öppnas och stängs.

  • macOS, iPad

    [ SKISS ]

    Fönsterappen. iPad och den vikbara iPhonen liggande.

  • Android, klocka

    [ SKISS ]

    Android, watchOS och Fitbit Sense. Samma logg, samma vakter.

  • webb och export

    [ SNART ]

    v4: webben, plus export till Fortnox och Kleer.
