hk ett skal för hela arbetsytan

Ett kommando där utvecklaren och agenten ser samma sanning om syskonprojekten: vad som finns, hur det körs och vilken form det ska ha. Hypotesen: en agent är produktiv efter ett kommando, hk context. En människa efter ett, hk ls.

// TRE JOBB

läsbar

Vad finns, i vilket skick, och vad pågår.

  • hk ls
  • hk status
  • hk context
  • hk goals
  • hk mcp

körbar

Projektets egna verktyg, alltid samma ingång.

  • hk dev
  • hk build
  • hk test
  • hk verify

konsekvent

Samma form i varje repo. Projektet har sista ordet.

  • hk new
  • hk sync
  • hk migrate
  • hk doctor
  • hk worktree

// VILLKOR FÖR ATT FLYTTA UT

Residenter bor gratis. Men inte för evigt.

När hk bär flyttar den till huvudkontoret.dev/hk och den här adressen pekar vidare med ->.

  • -> Ett kommando till produktiv. hk context för agenten, hk ls för människan.
  • -> Scopefrågor dör på en minut. Läser den? In. Skriver den? Bara form. Kör den? Bara genom delegering.
  • -> Ett eget lager. Länka ~/.config/hk/defaults från ditt dotfiles-repo så delar hk sync ut filerna till varje projekt.
